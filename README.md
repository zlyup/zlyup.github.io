# zlyup博客

一个具有**过渡效果**的个人博客站。上层展示 GitHub 个人资料，下层展示仓库列表作为博客文章，中间通过**四层高级视觉特效**实现自然的滚动过渡。

[✨ 在线预览](https://zlyup.github.io) | [📖 项目文档](#) | [🐛 反馈 Issues](https://github.com/zlyup/zlyup.github.io/issues)

---

## ✨ 特性

- 🎬 **电影级过渡** - 光晕、胶片颗粒、RGB色散、烟雾粒子四层特效
- 📊 **GitHub 实时数据** - 通过 API 获取真实头像、粉丝数、仓库列表
- 📱 **全平台适配** - 手机、平板、电脑完美响应式设计
- 🖱️ **点击直达项目** - 每个仓库卡片可点击，打开对应 GitHub Pages
- 🔄 **本地数据备份** - API 失败时自动使用预设数据
